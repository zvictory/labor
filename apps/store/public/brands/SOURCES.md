# Brand logo provenance

Every file here is a trademark of the house it names, used to identify goods the
shop sells. The ones fetched in September 2026 carry the exact URL they came
from, and every one was looked at on a contact sheet before it was wired into
`lib/catalog/media-manifest.ts`. That step is not optional: an automated fetch
cannot tell a wordmark from the wrong company's logo, and it has already got it
wrong — a Wikidata search for this shop's own name returned the Australian Labor
Party, and the file inherited for Ex Nihilo was the Ubuntu Linux logo.

White-on-transparent wordmarks were repainted graphite by
`scripts/normalize-brand-logo.ts` so they are visible on the off-white card.
Only the ink changed; the letterforms are the house's own.

## Deliberately absent

Not every brand card is meant to carry a logo.

- `labor` — the shop's own line. It is the site's own logotype, not a
  third-party mark, and it is set in Story Script in the header.
- `sofderm`, `okiii`, `creation`, `mix`, `khaltat`, `never-lies` — these are
  not perfume houses. The import made brands out of product names: sofderm is
  hand sanitiser and cream soap, okiii is empty refillable bottles, khaltat is a
  single Attar Collection fragrance. They have no logo because they are not
  brands.
- `maison-francis-kurkdjian`, `tiziana-terenzi` — both sites sit behind bot
  detection (Akamai and Cloudflare). Not worked around; these need a file.
- `rosendo-mateu` — site returns 503.
- `kinski` — a real house with one fragrance and no reachable site.
